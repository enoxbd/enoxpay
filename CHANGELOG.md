# Changelog

## `v1.0.0` — Initial Public Release

### Highlights
- **Automated SMS & Notification Payment Gateway** supporting bKash, Nagad, Rocket, Upay, and custom regex rules.
- **Signed Real-time Webhooks** (`X-Enox-Signature` HMAC-SHA256, Bearer/API-Key/custom headers, JSON template variables, live ping testing, and `WorkManager` retry queues).
- **Smooth Motion & UI Polish**:
  - Hardware-accelerated circular theme reveal between Light and Dark modes.
  - Smooth damped overscroll and clean pull-to-refresh indicator.
  - Symmetric Cupertino slide/parallax screen navigation and reverse back transitions.
  - Compact responsive header typography on Transactions history.
- **Reliability & Monitoring**:
  - Analytics dashboard, transaction inspector, trash recovery, and CSV export.
  - Telegram bot alerts and scheduled health heartbeats.
  - Real-time remote policy checks on launch/resume plus 5-minute background/foreground watchdog verification.
